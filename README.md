# BiDaTo Group — sitio one-page

Implementación responsive en React y vinext para OpenAI Sites, con animaciones GSAP y los activos visuales originales de BiDaTo.

## Ejecutar localmente

```bash
npm install
npm run dev
```

## Compilar para producción

```bash
npm run build
```

El resultado optimizado para Sites se genera en `dist/`.

## Dirección del sitio

- Narrativa AIDA continua, desde la transformación operacional hasta el contacto.
- Posicionamiento transversal: procesos, datos, automatización e inteligencia artificial.
- Salud presentada como experiencia comprobada, no como categoría central de la marca.
- Motion con entrada editorial, revelado de texto, progresión de método y scroll fijado en escritorio.
- Respeto por `prefers-reduced-motion` y navegación móvil accesible.
